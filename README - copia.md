# D18 Script Agent

**D18 Script Agent** is the first AI agent developed under **DADEUS AI**, focused on screenplay and script development.

D18 is designed to assist creators throughout the development of a screenplay, providing an AI-powered workspace for developing, reviewing and managing scripts.

## Version

**V1.0.0 — Initial Release**

## Developed by

**DADEUS AI**

> DADEUS AI is currently an independent project and is not yet incorporated as a registered company.

## Features

- AI-assisted screenplay development
- Script and project management
- Version management
- Context-aware conversations
- Local AI processing
- Integration with Ollama
- Local storage of project information
- Tools designed specifically for script development

## Local-first architecture

D18 is designed to operate locally on the user's computer.

D18 uses **Ollama** to run the AI model locally. Script content and project information are not intentionally transmitted to DAEDAL AI servers.

This means that your screenplay remains on your computer unless you independently configure other software or services to transmit it elsewhere.

## Requirements

- Windows PC
- Ollama installed and running
- The AI model required by D18
- Sufficient system resources to run the selected AI model

The exact hardware requirements may vary depending on the AI model used.

## Installation

1. Download the official D18 installer from the GitHub Release corresponding to the desired version.
2. Run the installer.
3. Follow the installation instructions.
4. Make sure Ollama is installed and running.
5. Launch D18 Script Agent.
6. Begin creating and developing your project.
