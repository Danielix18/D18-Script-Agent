FAQ / QUESTIONS

Frequently asked questions.

It is a desktop AI writing assistant developed by DADEUS AI.

Does D18 use cloud AI?

Its intended configuration uses Ollama to run a language model locally on your computer.

Which AI model does it use?

The current V1.0.0 configuration uses Llama 3.1 8B through Ollama.

Which operating system is supported?

The current public release is designed for Windows.

Where can I download D18?

The latest releases and installation files are available on the project's GitHub Releases page.
