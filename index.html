01 / The project

Technology meets the art of cinema.

D18 Script Agent is a desktop AI writing assistant developed by DADEUS AI. It is designed to support the creative development of cinematic stories, screenplays and film projects. Its local-first architecture connects to Ollama to run a language model on your own computer.

04 / Technology

A local-first architecture.

D18 combines a lightweight desktop interface with a locally running language model.

Python Tkinter Ollama Llama 3.1 8B Local AI Windows

System requirements

A Windows computer, Ollama installed and configured, a compatible local model, and sufficient memory and storage. Internet access may be needed to download the software and model.

05 / Privacy

Your work. Your computer.

D18 is designed to work with a locally running Ollama instance. Model processing takes place on your computer when using that local setup. Internet access may still be required for downloads and updates. Consult the project privacy documentation for details.

Frequently asked questions.

It is a desktop AI writing assistant developed by DADEUS AI, focused on cinematic storytelling and screenwriting.

Does it use cloud AI?

Its intended configuration uses Ollama to run a language model locally on your computer.

The current V1.0.0 configuration uses Llama 3.1 8B through Ollama.

Which operating system is supported?

The current public release is designed for Windows.
