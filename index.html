01 / About the project

Technology meets cinema.

D18 Script Agent is an AI-powered writing assistant developed by DAEDAL AI. Its purpose is to support filmmakers and screenwriters during the creative development of cinematic stories.

Built around local AI technology, the application connects to Ollama to run a language model on the user's own computer.

D18 Script Agent is the first public product in the D18 software project.

Built with accessible technology.

D18 Script Agent combines a lightweight desktop interface with a locally running language model.

Python Tkinter Ollama Llama 3.1 8B Local AI Windows

System requirements

  • Windows computer.
  • Ollama installed and configured.
  • Compatible local language model.
  • Enough available memory and storage to run the selected model.
  • Internet access may be needed to download the application and model.
05 / Privacy

Local-first AI.

D18 Script Agent is designed to work with a locally running Ollama instance. Model processing takes place on the user's computer when using that local setup.

Internet access can still be required for downloading software, models or updates. Consult the project's privacy documentation for further information.

07 / FAQ

Frequently asked questions.

What is D18 Script Agent?

It is a desktop AI writing assistant developed by DAEDAL AI, focused on cinematic storytelling and screenwriting.

Does it use cloud AI?

Its intended configuration uses Ollama to run a language model locally on the user's computer.

What AI model does it use?

The current V1.0.0 configuration uses Llama 3.1 8B through Ollama.

Which operating system is supported?

The current public release is designed for Windows.

Where can I download it?

The available releases and installation files can be found on the project's GitHub Releases page.
